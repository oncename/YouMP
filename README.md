## 📖 Обзор

**YouMP Media Pro** — профессиональная NLE-платформа (Non-Linear Editing) для работы с видео, аудио и изображениями. Объединяет мощный мультитрековый таймлайн, аппаратное ускорение через Direct3D 11, Zero‑Copy декодирование через FFmpeg и продвинутые инструменты монтажа в едином интерфейсе.

> ⚡ **Ключевое преимущество:** рендеринг таймлайна и воспроизведение выполняются **исключительно на GPU** (Direct3D 11) без использования GDI+, что обеспечивает плавность даже при работе с 4K‑контентом.

## ✨ Ключевые возможности

### 🎥 Профессиональный NLE‑таймлайн
- **Мультитрековая архитектура** — неограниченное количество видео и аудио дорожек
- **Перетаскивание клипов** мышью с магнитным прилипанием (Snapping)
- **Тримминг** левой и правой границ клипов
- **Разделение клипов** (Split) — горячая клавиша `S`
- **Undo / Redo** — полноценная система отмены действий (Ctrl+Z / Ctrl+Y)
- **Зум и панорамирование** таймлайна — колесо мыши + Shift

### 🎨 Визуальные эффекты
- **Fade In / Fade Out** для видео и аудио с выбором кривых (Linear, Fast, Slow, Smooth, Sharp)
- **Регулировка громкости** на уровне дорожки и клипа
- **Picture‑in‑Picture (PiP)** — масштаб, поворот, смещение X/Y для каждого видеоклипа
- **Кроп (кадрирование)** выделением прямоугольника на превью

### ⚡ Аппаратное ускорение
- **Zero‑Copy декодирование** через D3D11VA (аппаратное декодирование H.264/H.265/AV1)
- **GPU‑рендеринг таймлайна** с использованием Direct2D на D3D11‑поверхности
- **Автоматический выбор** между NVIDIA NVENC, AMD AMF и программным кодированием
- **Пул GPU‑кадров** для мгновенного скраббинга без лагов

### 🔊 Аудио
- **Два аудиодвижка** — WASAPI (Shared Mode) и ASIO (Low Latency)
- **Замена звуковой дорожки** на внешний файл
- **Регулировка задержки аудио** (A/V Sync) с визуальным индикатором на таймлайне
- **Визуализация аудиоволн** для каждого клипа

### 🖥️ Интерфейс
- **Полная поддержка светлой/темной темы** (Win11 Mica + DWM)
- **Инспектор свойств** — редактирование PiP‑параметров выделенного клипа
- **Всплывающее окно плеера** (Popout) с Fullscreen‑режимом
- **Drag & Drop** — загрузка файлов перетаскиванием на таймлайн

🎯 Основные модули (детально)
1. NativeMediaDecoder (C#)
Аппаратное декодирование через D3D11VA с Zero‑Copy передачей текстур.
Точный Seek с использованием av_rescale_q для коррекции PTS.
Мягкий фолбэк на софтверный SWScale при ошибках GPU.
Управление временем жизни через av_buffer_ref и освобождение в фоновом потоке.
2. AsyncMediaDecoder (VB.NET)
Асинхронная обёртка над нативным декодером с поддержкой отмены через CancellationToken.
Использует SemaphoreSlim для потокобезопасного доступа.
Поддерживает как аппаратное (Zero‑Copy), так и программное извлечение кадров.
3. TileTimelineRenderer
Рендеринг таймлайна в реальном времени на D3D11‑поверхности через Direct2D.
Асинхронная подгрузка миниатюр через GpuFrameExtractor с кэшированием в GpuFrameCacheManager.
Отображение аудиоволн, огибающих громкости, маркеров, кривых фейдов.
Поддержка магнитного прилипания (snapping) и интерактивного редактирования.
4. PlaybackController
Оркестрация синхронизации видео и аудио по единому Master Clock.
Компенсация аппаратных задержек звуковой карты (читает IAudioPlayer.OutputLatencyMs).
Плавное сглаживание громкости (TimeIndependentVolumeSmoother) и обработка перехода через маркеры.
5. ExportService (в MainEditorPresenter)
Экспорт с кадрированием, масштабированием, фейдами, заменой аудио.
Выбор аппаратного кодека (NVENC/AMF) через FFmpegCommandBuilder.
Поддержка сложных вырезаний (Cut Regions) и мультитрековой композиции.
6. NAudioSyncPlayer
Мультитрековый микшер с поддержкой NLE‑клипов (класс NleMultitrackProvider).
Динамическое изменение скорости (PlaybackRate) и громкости.
Поддержка WASAPI (Shared) и ASIO (Low Latency) через NAudio.
7. ProjectModel
Центральная модель проекта, содержащая список треков (TrackModel), каждый из которых содержит клипы (MediaClip).
Поддерживает операции добавления/удаления клипов, разделения, перемещения между треками.
Включает систему Undo/Redo через паттерн Command.
Управляет маркерами, зумом и панорамированием таймлайна.
